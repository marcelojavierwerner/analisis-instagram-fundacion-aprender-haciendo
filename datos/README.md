# Datos

El análisis se realizó sobre una muestra de 100 publicaciones públicas de Instagram de Fundación Aprender Haciendo.

Los datos fueron organizados y preparados inicialmente mediante Excel y posteriormente procesados mediante Python y Pandas.

## Variables principales

- `id`: identificador de la publicación.
- `isVideo`: indica si la publicación corresponde a un video.
- `likeCount`: cantidad de "me gusta".
- `commentCount`: cantidad de comentarios.
- `caption`: texto asociado a la publicación.
- `postDate`: fecha y hora de publicación.
- `postUrl`: URL de la publicación.

A partir de estas variables se generaron características adicionales para el análisis exploratorio, incluyendo variables temporales, longitud del texto, cantidad de hashtags, clasificación temática y nivel de interacción.

## Consideraciones

El dataset corresponde a publicaciones públicas y fue utilizado exclusivamente con fines de análisis descriptivo y académico/profesional.

El archivo de datos original no se incluye actualmente en el repositorio.
